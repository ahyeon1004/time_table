시간표 · BSSM — macOS 위젯 무료 배포판 (베타)

지원: macOS 14 이상, Apple Silicon 및 Intel Mac
가격: 무료. Xcode나 Apple 개발자 계정이 필요하지 않습니다.

설치
1. ZIP을 내려받아 압축을 풉니다.
2. BSSMTimetable.app을 Finder의 ‘응용 프로그램’ 폴더로 옮깁니다.
3. 앱을 한 번 실행합니다.
4. 바탕화면을 우클릭 → ‘위젯 편집’에서 BSSMTimetable 또는 시간표를 찾습니다.
5. 앱의 ‘학교 계정 로그인 · 위젯 연결’을 눌러 학교 계정으로 로그인합니다.
6. 시간표의 ‘알림 설정 → 맥 시간표 위젯’에서 ‘위젯 연결 코드 만들기 → 코드 복사’를 누릅니다.
7. 위젯을 추가한 뒤 우클릭 → ‘위젯 편집’의 ‘위젯 연결 코드’에 붙여 넣습니다.
이후 계정의 학년·반 변경은 자동으로 반영됩니다. 연결 전에는 1-1반을 임의로 표시하지 않습니다.
코드는 다른 사람에게 공유하지 마세요. 로그아웃·90일 만료·모든 위젯 연결 해제 시 새 코드로 연결해야 합니다.

첫 실행 안내
이 앱은 Apple 공증을 받지 않은 무료 배포판입니다. 개발자 확인 경고가 표시될 수 있습니다.
공식 다운로드 주소와 파일이 맞는지 확인한 경우에만 macOS가 제공하는 ‘개인정보 보호 및 보안’의 해당 앱 실행 허용 절차를 직접 진행하세요.
참고: https://support.apple.com/ko-kr/102445
학교·회사 관리 기기에서 실행이 제한되면 관리자에게 문의하세요.

표시 내용
- 현재·다음 수업, 선생님, 기본 시작 시각
- 시작 5분 전 ‘곧 시작’ 표시
- 작은·중간·큰 위젯
- 클릭하면 시간표 웹 열기
- 나이스 실제 시간표와 웹의 과목명·교사명 변환 사용

제한
- 웹에서 설정한 개인별 이동 교실·단축수업은 동기화되지 않습니다.
- 위젯 갱신은 macOS가 관리하며 정확한 초 단위 갱신을 보장하지 않습니다.
- 오늘 수업이 없으면 ‘등록된 수업 없음’을 표시합니다.
- 웹 푸시 알림은 별도로 설정하는 기존 기능입니다.
- 제작자 맥에서 빌드·실행, 서버 연결·JSON 해석 및 CPU 두 종류 포함을 확인했습니다.
  다른 사람의 맥에서 위젯 등록·표시까지는 아직 검증하지 않은 베타입니다.
